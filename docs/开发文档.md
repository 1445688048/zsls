## 三、数据库 DDL

```sql
CREATE EXTENSION IF NOT EXISTS vector;

-- 用户表
CREATE TABLE app_user (
    user_id        BIGSERIAL PRIMARY KEY,
    openid         VARCHAR(64) UNIQUE NOT NULL,
    nickname       VARCHAR(128),
    created_at     TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 案件档案
CREATE TABLE case_profile (
    case_id        BIGSERIAL PRIMARY KEY,
    user_id        BIGINT REFERENCES app_user(user_id),
    domain_type    VARCHAR(32) NOT NULL DEFAULT 'LABOR',
    status         VARCHAR(32) NOT NULL DEFAULT 'COLLECTING',
    title          VARCHAR(256),
    facts_json     JSONB NOT NULL DEFAULT '{}',
    issues_json    JSONB NOT NULL DEFAULT '[]',
    laws_json      JSONB NOT NULL DEFAULT '[]',
    timeline_json  JSONB NOT NULL DEFAULT '[]',
    evidence_refs  JSONB NOT NULL DEFAULT '[]',
    created_at     TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at     TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 对话会话
CREATE TABLE chat_session (
    session_id     BIGSERIAL PRIMARY KEY,
    case_id        BIGINT REFERENCES case_profile(case_id),
    user_id        BIGINT REFERENCES app_user(user_id),
    summary        VARCHAR(512),
    created_at     TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 对话消息
CREATE TABLE chat_message (
    message_id     BIGSERIAL PRIMARY KEY,
    session_id     BIGINT REFERENCES chat_session(session_id),
    role           VARCHAR(16) NOT NULL,
    content        TEXT NOT NULL,
    evidence_refs  JSONB,
    created_at     TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 法律之星查询缓存
CREATE TABLE law_cache (
    cache_key      VARCHAR(128) PRIMARY KEY,
    source         VARCHAR(32) NOT NULL,
    response_json  JSONB NOT NULL,
    expires_at     TIMESTAMP NOT NULL,
    created_at     TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- LLM 配置
CREATE TABLE llm_config (
    config_id      BIGSERIAL PRIMARY KEY,
    user_id        BIGINT REFERENCES app_user(user_id),
    provider_name  VARCHAR(64) NOT NULL,
    base_url       VARCHAR(256),
    api_key        VARCHAR(256) NOT NULL,
    model_name     VARCHAR(64),
    temperature    DECIMAL(3,2) DEFAULT 0.3,
    max_tokens     INT DEFAULT 4096,
    is_active      BOOLEAN DEFAULT TRUE,
    created_at     TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 向量表
CREATE TABLE domain_knowledge_vector (
    id             BIGSERIAL PRIMARY KEY,
    domain_type    VARCHAR(32) NOT NULL,
    content_type   VARCHAR(32) NOT NULL,
    content_id     VARCHAR(64) NOT NULL,
    text_chunk     TEXT NOT NULL,
    embedding      vector(1536),
    metadata_json  JSONB DEFAULT '{}',
    created_at     TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_dkv_domain ON domain_knowledge_vector(domain_type);
CREATE INDEX idx_dkv_content_type ON domain_knowledge_vector(content_type);
```

```java
@Service
public class DynamicChatModelService {
    
    @Autowired
    private LLMConfigService llmConfigService;
    
    /**
     * 根据用户配置创建 ChatModel
     */
    public ChatModel createChatModel(Long userId) {
        LLMConfig config = llmConfigService.getActiveConfig(userId);
        if (config == null) {
            throw new IllegalStateException("请先配置 LLM API Key");
        }
        
        return switch (config.getProviderName().toLowerCase()) {
            case "deepseek" -> createOpenAICompatibleModel(
                "https://api.deepseek.com/v1",
                config.getApiKey(),
                config.getModelName(),
                config.getTemperature(),
                config.getMaxTokens()
            );
            case "openai" -> createOpenAICompatibleModel(
                "https://api.openai.com/v1",
                config.getApiKey(),
                config.getModelName(),
                config.getTemperature(),
                config.getMaxTokens()
            );
            case "zhipu" -> createZhipuModel(
                config.getApiKey(),
                config.getModelName(),
                config.getTemperature(),
                config.getMaxTokens()
            );
            default -> throw new IllegalArgumentException("不支持的 LLM 提供商: " + config.getProviderName());
        };
    }
    
    private OpenAiChatModel createOpenAICompatibleModel(
        String baseUrl, String apiKey, String model, 
        Double temperature, Integer maxTokens
    ) {
        OpenAiApi api = new OpenAiApi(baseUrl, apiKey);
        OpenAiChatOptions options = OpenAiChatOptions.builder()
            .withModel(model)
            .withTemperature(temperature)
            .withMaxTokens(maxTokens)
            .build();
        return new OpenAiChatModel(api, options);
    }
    
    private ZhipuAiChatModel createZhipuModel(
        String apiKey, String model, 
        Double temperature, Integer maxTokens
    ) {
        ZhipuAiApi api = new ZhipuAiApi(apiKey);
        ZhipuAiChatOptions options = ZhipuAiChatOptions.builder()
            .withModel(model)
            .withTemperature(temperature)
            .withMaxTokens(maxTokens)
            .build();
        return new ZhipuAiChatModel(api, options);
    }
}
```

#### 3.4 ChatService 实现

```java
@Service
public class ChatService {
    
    @Autowired
    private DynamicChatModelService chatModelService;
    
    /**
     * 流式对话（SSE）
     */
    public Flux<String> chatStream(Long userId, List<Message> messages) {
        ChatModel chatModel = chatModelService.createChatModel(userId);
        
        Prompt prompt = new Prompt(messages);
        
        return chatModel.stream(prompt)
            .map(chatResponse -> {
                if (chatResponse.getResult() != null && 
                    chatResponse.getResult().getOutput() != null) {
                    return chatResponse.getResult().getOutput().getContent();
                }
                return "";
            })
            .filter(content -> !content.isEmpty());
    }
    
    /**
     * 非流式对话
     */
    public String chat(Long userId, List<Message> messages) {
        ChatModel chatModel = chatModelService.createChatModel(userId);
        
        Prompt prompt = new Prompt(messages);
        ChatResponse response = chatModel.call(prompt);
        
        return response.getResult().getOutput().getContent();
    }
}
```

#### 5.1 AgentOrchestrator 主流程

```java
@Service
public class AgentOrchestrator {
    
    @Autowired
    private DynamicChatModelService chatModelService;
    @Autowired
    private CaseProfileService caseProfileService;
    @Autowired
    private ChatMessageService chatMessageService;
    @Autowired
    private DomainPluginLoader pluginLoader;
    @Autowired
    private PromptBuilder promptBuilder;
    @Autowired
    private FactExtractor factExtractor;
    @Autowired
    private EvidenceAdvisor evidenceAdvisor;
    @Autowired
    private LawStarClient lawStarClient;
    
    /**
     * 主对话流程（流式）
     */
    public Flux<String> chat(Long userId, Long caseId, Long sessionId, String userMessage) {
        // ① 保存用户消息
        ChatMessage userMsg = saveUserMessage(sessionId, userMessage);
        
        // ② 加载 CaseProfile
        CaseProfile caseProfile = caseProfileService.getById(caseId);
        
        // ③ 加载领域插件
        DomainPlugin plugin = pluginLoader.getPlugin(caseProfile.getDomainType());
        
        // ④ 构建 Prompt
        List<Message> messages = promptBuilder.build(caseProfile, plugin, userMessage);
        
        // ⑤ 创建 ChatModel 并流式调用
        ChatModel chatModel = chatModelService.createChatModel(userId);
        Prompt prompt = new Prompt(messages);
        
        StringBuilder fullResponse = new StringBuilder();
        
        return chatModel.stream(prompt)
            .map(chatResponse -> {
                String content = chatResponse.getResult().getOutput().getContent();
                fullResponse.append(content);
                return content;
            })
            .doOnComplete(() -> {
                // ⑥ 流式输出结束后，异步执行后处理
                processAfterChat(userId, caseId, sessionId, caseProfile, plugin, fullResponse.toString());
            });
    }
    
    /**
     * 后处理（异步）
     */
    @Async
    protected void processAfterChat(Long userId, Long caseId, Long sessionId, 
                                     CaseProfile caseProfile, DomainPlugin plugin, 
                                     String assistantResponse) {
        // a. 保存 Assistant 消息
        saveAssistantMessage(sessionId, assistantResponse);
        
        // b. 提取事实要素
        Map<String, FactValue> extractedFacts = factExtractor.extract(userId, assistantResponse);
        caseProfile.getFactsJson().putAll(extractedFacts);
        
        // c. 检查早期预警
        if (triggerEarlyWarning(assistantResponse, plugin)) {
            // 触发预警逻辑
        }
        
        // d. 引用法条（如需要）
        if (needsLawReference(assistantResponse)) {
            List<LawReference> laws = lawStarClient.searchLaws(assistantResponse);
            caseProfile.setLawsJson(laws);
        }
        
        // e. 保存更新后的 CaseProfile
        caseProfileService.updateById(caseProfile);
    }
}
```

#### 5.4 EvidenceAdvisor 实现

```java
@Service
public class EvidenceAdvisor {
    
    /**
     * 根据当前案情判断还缺哪些证据
     */
    public List<EvidenceAdvice> advise(DomainPlugin plugin, Map<String, FactValue> facts) {
        List<EvidenceAdvice> advices = new ArrayList<>();
        
        // 检查必要证据
        for (EvidenceItem necessary : plugin.getEvidenceRules().getNecessary()) {
            if (!hasEvidence(necessary, facts)) {
                advices.add(new EvidenceAdvice(
                    necessary.getName(),
                    necessary.getDescription(),
                    "必要",
                    "请收集：" + necessary.getDescription()
                ));
            }
        }
        
        // 检查增强证据
        for (EvidenceItem enhancing : plugin.getEvidenceRules().getEnhancing()) {
            if (isApplicable(enhancing, facts) && !hasEvidence(enhancing, facts)) {
                advices.add(new EvidenceAdvice(
                    enhancing.getName(),
                    enhancing.getDescription(),
                    "增强",
                    "建议收集：" + enhancing.getDescription()
                ));
            }
        }
        
        return advices;
    }
}
```

## 八、隐私方案实现

### 方案 A（默认模式 — 零隐私风险）
- 用户上传文件仅存微信小程序本地存储（`wx.setStorageSync` 或文件系统）
- 发送给后端时，**只传文件的 metadata**（文件名、类型、大小）

- 后端将脱敏文本 + 用户描述一起发给 LLM
- LLM 返回分析结果后，前端用映射表将占位符还原（仅本地展示）

### 全局要求
- 隐私政策文本在 `pages/disclaimer` 中维护
- 首次启动弹窗，用户必须点击"同意"才能进入小程序

## 十一、关键注意事项

### 11.1 Spring AI 2.0 相关

1. **SSE 流式输出**：
   - Spring AI 2.0 的 `ChatModel.stream()` 返回 `Flux<ChatResponse>`
   - Controller 直接返回 `Flux<String>`，Spring Boot 自动处理 SSE
   - 前端用 `wx.request` 的 `enableChunked: true` 接收
   - 示例：`return chatModel.stream(prompt).map(r -> r.getResult().getOutput().getContent());`

2. **动态模型切换**：
   - 每次对话时根据用户配置动态创建 `ChatModel` 实例
   - 不使用 Spring AI 的自动配置，而是手动创建 `OpenAiApi` / `ZhipuAiApi`
   - API Key 从数据库读取（AES-256 加密存储）

3. **DeepSeek 兼容性**：
   - DeepSeek API 完全兼容 OpenAI 格式
   - 使用 `spring-ai-openai` 模块，修改 `base-url` 为 `https://api.deepseek.com/v1`
   - 模型名称：`deepseek-chat` 或 `deepseek-reasoner`

4. **智谱 GLM 特殊处理**：
   - 使用 `spring-ai-zhipuai` 模块
   - 模型名称：`glm-4-flash`（快速）、`glm-4`（标准）、`glm-4-plus`（高级）

### 11.2 数据与安全

5. **法律之星缓存 key**：
   - `cache_key = SHA256(source + JSON.stringify(params))`
   - 过期时间 24h
   - 使用 Caffeine 本地缓存

6. **向量存储抽象**：
   - Spring AI 2.0 内置 `VectorStore` 接口
   - 第一版用 `PgVectorStore` 实现（Spring AI 提供）
   - 后续换 Milvus 只需修改配置

7. **LLM 输出中的日期计算**：
   - 不要让 LLM 算时效截止日
   - 后端用规则引擎根据 `processTemplate.steps[n].deadlineRule` + 事实要素中的时间点
   - 用 Java `LocalDate` 计算后注入到时间轴

8. **敏感信息加密**：
   - `llm_config.api_key` 存入前 AES-256 加密
   - 读取时解密后注入到 `ChatModel` 创建方法
   - 使用 `CryptoUtils.encrypt()` / `decrypt()`

```powershell
# 方式一：winget 安装（推荐，无需 Docker）

psql -U postgres
```
